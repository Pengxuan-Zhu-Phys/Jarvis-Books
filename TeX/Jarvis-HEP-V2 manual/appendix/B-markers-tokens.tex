\chapter{Markers \& Tokens}
\label{app:markers-tokens}

The complete token language (Section~\ref{sec:tokens}). \emph{Phase 1} resolves once at
card load, in the control process; \emph{Phase 2} resolves per Sample, inside the
Worker. A Phase-1 token surviving into Phase 2 is an error; Phase-2 tokens pass through
Phase 1 untouched, so one string may mix both.

\paragraph{Where each may appear.}

\begin{itemize}
  \item Phase-1 tokens: any path-like or command field --- \yamlkey{path},
        \yamlkey{source}, \yamlkey{cmd}, \yamlkey{cwd}, \yamlkey{data},
        \yamlkey{CSV.path}, \yamlkey{default\_yaml\_path}, \ldots
  \item \token{@SampleID} / \token{@Sdir}: calculator \yamlkey{execution} commands and
        I/O spec paths.
  \item \token{@PackID}: module \yamlkey{path} and commands of \yamlkey{clone\_shadow}
        modules (and anywhere pack traceability is wanted).
  \item \code{\$\{source\}} / \code{\$\{path\}}: only inside
        \yamlkey{installation}/\yamlkey{initialization} command lists.
\end{itemize}

\paragraph{Worked example.}

\begin{yamlwin}
cmd: "spheno ${LibDeps:SPheno}/templates/base.in @Sdir/@SampleID.out"
\end{yamlwin}

Phase 1 turns \code{\$\{LibDeps:SPheno\}} into an absolute path (and \code{spheno} into
one, if registered); Phase 2, in the Worker, fills \token{@Sdir} and \token{@SampleID}
for each Sample.
