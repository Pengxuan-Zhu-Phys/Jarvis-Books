\chapter{Task Card Gallery}
\label{app:gallery}

Complete, minimal cards for the recurring shapes. All run as-is (the opera-based ones
need nothing beyond the core install); swap the toy operators for your physics. More
worked projects: \cli{Jarvis project list} (Chapter~\ref{ch:project-cli}).

\section{Random + opera (the smoke card)}

\begin{yamlwin}
Scan: {name: gallery-random}
EnvReqs:
  V2: {workers: 2}
Sampling:
  Method: Random
  Bounds:
    point_number: 100
    seed: 7
  Variables:
    - {name: x, distribution: {type: Flat, parameters: {min: 0.0, max: 1.0}}}
    - {name: y, distribution: {type: Flat, parameters: {min: 0.0, max: 1.0}}}
  LogLikelihood:
    - {name: LogL_Z, expression: z}
Operas:
  Modules:
    - name: EggBox
      operator: jarvishep2.testing.eggbox.eggbox2d_numpy
      input:  [{name: x, expression: x}, {name: y, expression: y}]
      output: [{name: z, entry: z}]
\end{yamlwin}

\section{Bridson + external calculator}

\begin{yamlwin}
Scan: {name: gallery-bridson}
EnvReqs:
  V2: {workers: 8}
LibDeps:
  path: "&J/External"
  Modules: [{name: EggBoxSafe}]
  registered_executables:
    - {name: eggboxlk, source: "\${LibDeps:EggBoxSafe}/eggbox"}
Sampling:
  Method: Bridson
  Bounds:
    radius: 0.05
    max_attempt: 30
    seed: 42
  Variables:
    - {name: x, distribution: {type: Flat,
         parameters: {min: 0.0, max: 1.0, length: 1.0}}}
    - {name: y, distribution: {type: Flat,
         parameters: {min: 0.0, max: 1.0, length: 1.0}}}
  LogLikelihood: [{name: LogL, expression: z}]
Calculators:
  Pools: {EggBox: 4}
  Modules:
    - name: EggBox
      timeout: 60
      execution:
        commands: [{cmd: python3 eggboxlk, cwd: "@Sdir"}]
        input:
          - name: inp
            path: "@Sdir/input.json"
            type: JSON
            actions:
              - type: Dump
                variables:
                  - {name: xx, expression: x * Pi}
                  - {name: yy, expression: y * Pi}
        output:
          - name: oup
            path: "@Sdir/output.json"
            type: JSON
            save: true
            variables: [{name: z, entry: z}]
\end{yamlwin}

\section{AdaptiveBridson (contour tracing)}

\begin{yamlwin}
Scan: {name: gallery-levelset}
EnvReqs:
  V2: {workers: 2, batch_size: 8}
Sampling:
  Method: AdaptiveBridson
  Variables:
    - {name: x, distribution: {type: Flat, parameters: {min: 0.0, max: 1.0}}}
    - {name: y, distribution: {type: Flat, parameters: {min: 0.0, max: 1.0}}}
  Bounds:
    target_expression: "r2"
    target_value: 0.04            # circle of radius 0.2 about (0.5, 0.5)
    outer_half_width: 0.05        # discovery band |f-T| <= w_outer
    min_radius: 0.01              # u-space resolution floor
    seed: 7
Operas:
  Modules:
    - name: Circle
      operator: jarvishep2.testing.eggbox.circle_r2
      input:  [{name: x, expression: x}, {name: y, expression: y}]
      output: [{name: r2, entry: r2}]
\end{yamlwin}

Produces \file{levelset.json} beside the normal outputs
(Chapter~\ref{ch:adaptive-levelset}).

\section{check\_modules (workflow validation)}

\begin{yamlwin}
Scan: {name: gallery-check}
EnvReqs:
  V2:
    workers: 1
    check_modules:
      data: "&J/data/check_points.csv"  # optional; columns are u-space, one
      n_samples: 10                     # per Variable (omit the file to draw
                                        # n_samples points from Method instead)
Sampling:
  Method: Random
  Bounds: {point_number: 10}
  Variables:
    - {name: x, distribution: {type: Flat, parameters: {min: 0.0, max: 1.0}}}
    - {name: y, distribution: {type: Flat, parameters: {min: 0.0, max: 1.0}}}
  LogLikelihood:
    - {name: LogL, expression: "LogGauss(z, 100, 10)"}
Operas:
  Modules:
    - name: EggBox
      operator: jarvishep2.testing.eggbox.eggbox2d_numpy
      input:  [{name: x, expression: x}, {name: y, expression: y}]
      output: [{name: z, entry: z}]
\end{yamlwin}

Run with \cli{Jarvis check gallery-check.yaml}; command output is mirrored to the
terminal (Chapter~\ref{ch:check-modules}). Nothing in the card selects the smoke path
--- the command does --- so this is an ordinary, complete scan card, and
\cli{Jarvis run} on the same file is the production scan.
